Understanding JavaScript If/Else Statements

What is an If/Else Statement?

In JavaScript, an if/else statement allows a program to make decisions based on certain conditions. It checks whether a condition is true or false and runs different code depending on the result.

How Does It Work?

The "if" statement checks a condition. If the condition is true, the code inside the if statement runs.

If the condition is false, the program skips the if statement and runs the code inside the else statement.

Example 1: Basic If/Else Statement

let age = 18;

if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are a minor.");
}

In this example, JavaScript checks whether the age is 18 or older. Since the age is 18, the condition is true, and the program displays "You are an adult."

Comparison Operators

JavaScript uses comparison operators to evaluate conditions.

  • == : Equal to (compares values)
  • === : Strictly equal to (compares value and type)
  • != : Not equal to
  • !== : Strictly not equal to
  • > : Greater than
  • < : Less than
  • >= : Greater than or equal to
  • <= : Less than or equal to

Why Are If/Else Statements Important?

If/else statements are important because they allow websites and applications to respond differently depending on user input or specific situations.

For example, websites use conditional statements to check passwords, determine discounts, calculate grades, and display personalized messages.

Conclusion

JavaScript if/else statements help programs make decisions. By checking conditions, JavaScript can determine which instructions should run. Understanding these statements is an important part of learning programming.
